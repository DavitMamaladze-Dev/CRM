CRM Platform

A full-stack Customer Relationship Management (CRM) application built with Next.js and Django REST Framework (DRF) to manage contacts, deals, tasks, and customer activities through an intuitive interface.

Features

- Contact Management: Create, view, and manage customer contacts.
- Deal Management: Organize and track deals throughout the sales pipeline.
- Drag-and-Drop Board: Move deals between pipeline stages using an interactive Kanban-style board.
- Task Management: Create and manage tasks associated with contacts and deals.
- Activity Tracking: Keep track of customer interactions and related activities.
- REST API: A Django REST Framework backend for handling application data and business logic.

Tech Stack

- Frontend: Next.js, React, JavaScript
- Backend: Django, Django REST Framework
- Database: SQLite
- HTTP Client: Axios

Project Goal

The goal of this project is to build a practical CRM platform that simplifies customer relationship management, sales pipeline tracking, and task organization through a modern web interface and a RESTful backend.
